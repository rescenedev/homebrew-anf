# homebrew-anf

[anf — all new finder](https://github.com/rescenedev/anf)의 Homebrew tap.

## 설치

```bash
brew install --cask rescenedev/anf/anf
```

또는:

```bash
brew tap rescenedev/anf
brew install --cask anf
```

> self-signed 빌드라 첫 실행 시 Gatekeeper가 막을 수 있습니다 —
> anf.app 우클릭 → 열기, 또는 시스템 설정 > 개인정보 보호 및 보안 > "확인 없이 열기".

## 업데이트

```bash
brew upgrade --cask anf
```
